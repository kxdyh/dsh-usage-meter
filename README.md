# dsh-usage-meter 用量与余额仪表

A DeepSeek Harness (dsh) plugin that keeps a **live usage and balance meter** at the foot of the
sidebar, so you can always see how full the context window is, how many tokens the session has
spent, and how much credit is left on your account — without opening a settings page.

一个 DeepSeek Harness（dsh）插件，在**侧边栏底部**常驻一个用量与余额仪表 —— 不用打开任何设置页，
就能随时看到上下文窗口用了多少、本会话消耗了多少 token、账号还剩多少余额。

```
上下文            45%   12.3K / 128K       ← 上下文窗口占用率 / 已用与上限
━━━━━━━━━━━━━━░░░░░░░░                     ← 占用条（≥70% 转琥珀色，≥90% 转红色）
余额                   ¥12.34              ← 当前登录账号的余额
```

## 显示什么 What you see

| 显示项 | 含义 |
|---|---|
| `上下文` 百分比 | 当前会话的上下文窗口占用率 —— 越接近 100% 越接近需要压缩历史的那条线 |
| `12.3K / 128K` | 已用 token / 该模型的上下文窗口上限 |
| 占用条 | 0–70% 灰、≥70% 琥珀、≥90% 红，一眼看出还剩多少余量 |
| `余额` | 你 DeepSeek 账号的剩余余额（按币种显示，优先显示 ¥；精确到小数点后面 7 位） |

**点击仪表**即可展开明细：输入 / 输出 / 缓存读取 / 缓存写入 token、赠送余额，以及一个 **↻ 刷新** 按钮 —— 余额平时每 60 秒自动更新一次，想立刻拿到最新数值时点它即可。

**侧边栏收起**为 56px 导轨时，仪表会自动变成一个紧凑的环形指示器，鼠标悬停仍可看到数值。

## 特点 Features

- **常驻侧边栏** —— 不用来回切换设置页，余光就能看到。
- **余额是真的** —— 直接读官方账号接口的余额，不是按 token 单价估算出来的。
- **余额精确到小数点后面 7 位** —— 如实保留平台返回的原始小数精度，不做「四舍五入到分」的处理。
- **可手动刷新** —— 展开明细后点一下 **↻ 刷新**，立即重新读取余额与用量，不用等下一次自动轮询。
- **上下文占用跟随回合增长** —— 接近上限时进度条会变色提醒你。
- **不增加负担** —— 不轮询模型、不额外发请求；token 数据是宿主本来就会推送的。
- **不依赖额外组件** —— 只用 dsh 自带的主题与插槽机制，dsh 升级时更不容易坏。
- **浅色 / 深色主题自适应**，中英双语界面。

## 常见问题 FAQ

**Q：余额一直显示「未登录」？**
需要先在 **设置 → 账号** 里登录 DeepSeek 账号。本插件只**读取**余额，不会发起登录、也不会读取或上传任何凭据。未登录时只有余额那一行显示「未登录」，token 用量照常显示。

**Q：token 数字不是逐字实时变的？**
正常的。宿主只在每一步推理**结束时**才结算用量，所以数字按"步"跳动。「上下文」百分比会随回合进行平滑增长，它才是那个看起来实时的数字。

**Q：为什么没有花费 / 花了多少钱？**
当前 dsh 的用量接口里没有费用字段，所以本插件不显示费用 —— 不猜、不估算。

**Q：统计的是当前会话还是全部会话？**
当前**会话**的累计值，不是跨会话汇总。

**Q：刷新页面或重连会不会丢？**
不会，数字由会话日志累计得出，重连后自动恢复。

**Q：侧边栏收起了看不到？**
收起时仪表会切换成环形指示器，仍显示占用比例与余额；展开侧边栏即可看到完整两行。

**Q：会影响性能或隐私吗？**
不会。插件不轮询模型、不发送任何额外请求；余额每 60 秒读一次官方接口。

## 安装 Install

**方式一 · 从 GitHub 安装（推荐）**

```bash
dsh plugin --profile <你的 profile> add github:kxdyh/dsh-usage-meter
```

**方式二 · 从 npm 安装**（发布后可用）

```bash
dsh plugin --profile <你的 profile> add @kxdyh/dsh-usage-meter
```

**方式三 · 从本地目录或 `.tgz` 包安装**

```bash
dsh plugin --profile <你的 profile> add /绝对路径/dsh-usage-meter
dsh plugin --profile <你的 profile> add /绝对路径/kxdyh-dsh-usage-meter-1.0.0.tgz
```

> 路径必须是**绝对路径**。

装好后**不需要重启**，侧边栏底部会立刻出现仪表。

## 卸载 Uninstall

在 dsh 的 **设置 → 插件** 里找到 `dsh-usage-meter`，点卸载即可（会同时取消选中、卸载运行时贡献并移除依赖）。

## 环境要求 Requirements

- dsh 桌面版或 Web 版，标准 `dsh-web-app` 组合即可，无需额外安装任何东西。
- 想看**余额**需要已登录 DeepSeek 账号（未登录时该行显示「未登录」）。
- **token 数字**需要该会话产生过一次模型用量后才会出现。
